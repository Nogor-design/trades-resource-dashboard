# Trades Resource Command Center — Developer Improvement Brief

## Objective

Improve the current Trades Resource Command Center demo so it is more focused, business-relevant, and client-meeting ready.

The current app already has strong functionality: Owner Today View, Active Assignment Forecast, Open Orders Board, Recruiter Process Tracker, Candidate Matching, Redeployment Planning, and Submittal Packets.

However, the next improvement pass should focus on making the demo clearly solve the owner’s actual pain:

> The owner is currently tracking active assignments in spreadsheets, open orders on paper, recruiter workflow through a candidate spreadsheet, and many important follow-ups from memory. She wants better forecasting so she can focus more on sales.

The app should feel like an **operations forecasting and workflow visibility system**, not just a polished dashboard and not just an AI demo.

---

# Core Business Problem

Trades Resource needs a practical command center that helps the owner answer:

1. Who is currently assigned?
2. What assignments are ending soon?
3. Which renewals or extensions need attention?
4. Who has upcoming time off?
5. Which open orders still need candidates?
6. Which submitted candidates are waiting on approval?
7. Which recruiter tasks or process steps are incomplete?
8. What needs attention today, this week, and in the next 30/60/90 days?
9. What can be system-tracked so the owner does not have to remember everything manually?

The demo should emphasize:

* Forecasting
* Active assignment tracking
* Renewal and extension visibility
* Upcoming time-off visibility
* Open order tracking
* Candidate approval tracking
* Recruiter process consistency
* Required-field completion
* Redeployment planning
* Owner sales focus

---

# Main Positioning Statement

The app should be framed around this idea:

> “Forecasting so the owner can focus on sales.”

The system should help move the business from:

> Spreadsheet + paper + memory

to:

> One operational command center showing assignments, open orders, recruiter workflow, renewals, extensions, time off, redeployment, and upcoming action items.

Avoid positioning this as “AI replacing recruiting.” The message should be:

> “This helps the owner and recruiter see what needs attention before it becomes urgent.”

---

# Recommended First-Meeting Demo Flow

Do not show every feature in the first client meeting. Focus on the four most relevant sections:

1. Owner Today View
2. Active Assignment Forecast
3. Open Orders Board
4. Recruiter Process Tracker

Candidate Matching, Redeployment Planning, and Submittal Packets can be shown briefly as future expansion areas only if the meeting is going well.

This is a concept prototype using demo data.

* Defining required fields
* Importing current active assignments
* Importing current open orders
* Importing candidate/recruiter process data

* Adding backup/export procedures
* Deciding where the system should live long-term

# Business Rules to Implement

## Assignment Forecast Rules

* Assignment ending within 30 days and no renewal status = renewal review needed
* Assignment ending within 14 days and extension status unknown = urgent extension follow-up
* Assignment ending within 7 days and no decision = critical forecast risk
* Assignment past projected end date and no redeployment = critical
* Worker not checked in within 14 days = check-in needed
* Client not contacted within 7 days near end date = client follow-up needed

## Time-Off Rules

* Time off within 14 days and client not notified = alert
* Time off within 7 days and coverage needed = urgent
* Time off overlaps assignment end date = forecast risk
* Time off status missing = incomplete data

## Open Order Rules

* Intake incomplete = stuck
* No candidates submitted = sourcing needed
* Open more than 7 days with no candidates submitted = stuck
* Candidate submitted more than 3 days ago with no client response = follow-up needed
* Target start date within 7 days and not filled = urgent
* Candidate approved but no interview scheduled = schedule interview
* Interview complete but no result = update needed

## Recruiter Process Rules

* Required fields missing = data completion needed
* Proficiency test missing = testing needed
* Spreadsheet/data not updated recently = update needed
* Follow-up overdue = overdue task
* Candidate submitted but no approval status = client response needed
* Interview scheduled but no result = update interview result

## Redeployment Rules

* Assignment ending within 30 days and redeployment not started = start redeployment planning
* Assignment ending within 14 days and worker not contacted = contact worker
* Assignment ending within 7 days and no extension/redeployment plan = critical
* Worker available soon and matching open order exists = review match
* No open match = possible sales/recruiting opportunity
